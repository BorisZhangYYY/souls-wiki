# 魂类维基百科

> **余烬法典 · THE ASHEN CODEX**
> 一部非官方的中文魂系世界观资料索引，收录黑暗之魂三部曲、《艾尔登法环》、《只狼：影逝二度》与《血源诅咒》的作品剧情、重要人物、标志性器物与世界观设定。

纯静态站点：多页 HTML + CSS + 原生 JavaScript，数据全部以纯文本 JS 文件维护，**无构建、无后端、无数据库**。

## 收录范围

| 作品 | 条目重点 |
| --- | --- |
| 黑暗之魂：重制版 | 初始之火、传火、乌拉席露与深渊 |
| 黑暗之魂 II：原罪学者 | 多兰古雷格、渴望王座、失落王冠三部曲 |
| 黑暗之魂 III | 五位薪王、艾雷德尔之烬、环印城 |
| 艾尔登法环 | 黄金律法、半神、破碎战争、黄金树幽影 |
| 只狼：影逝二度 | 龙胤、苇名、不死斩与四种结局 |
| 血源诅咒 | 血疗、上位者、猎人梦境、科斯的诅咒 |

**当前规模**：6 部作品词条（每部 5–6 段剧情脉络）、132 位人物、67 件剧情重要器物、25 条世界观辞条、11 条现实发售年表、7 幅原创氛围概念图。

## 页面

- `index.html` — 首页、六部作品入口、发售年表
- `works.html` / `work.html?id=…` — 作品总览与详情页（剧情、基本信息、区域、结局、本作人物与器物）
- `characters.html` — 人物志，支持按作品筛选与中英文关键词检索
- `equipment.html` — 器物志，支持筛选与检索
- `lore.html` — 世界观辞典与跨作品母题
- `about.html` — 美术档案、资料来源、编写原则与版权说明

## 本地预览

```bash
python3 -m http.server 8765 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8765/
```

也可直接用浏览器打开 `index.html`（脚本以相对路径加载，不需要构建或服务端）。

## 维护内容

新增或修改条目只需编辑对应的 `assets/js/data-*.js`，刷新页面即生效。人物与器物条目均带 `work` 字段关联作品，站内索引、作品页分组与筛选会自动更新。

## 编写原则

- 中文译名以简体中文通行译法为主，**每条均附英文原名**，以消除版本与地区差异（如「落叶／洛阳」「原罪学者／原罪哲人」）。
- 剧情以游戏内文本、道具说明与官方资料为依据；社区推论一律标注「解读／暗示／推测」，不把同人考据写成定论。
- 资料来源与各作品官方页面、资料库外链见 `about.html`。

## 图像与版权

- `assets/img/` 下 7 张配图是**本站委托 AI 生成的原创氛围概念图，不是 FromSoftware 的官方原画或设定稿**，也不代表角色与场景的官方造型。
- 游戏名称、角色、剧情与相关美术的著作权归 FromSoftware、Bandai Namco Entertainment、Sony Interactive Entertainment、Activision 等权利人所有。
- 本项目为**非官方、非商业**的爱好者资料索引；如需查阅官方美术与原始文本，请使用各作品详情页提供的外链。
